# Restaurant Management System

[![Java](https://img.shields.io/badge/Java-17%2B-orange?style=for-the-badge&logo=openjdk)](https://openjdk.org/)
[![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.x-brightgreen?style=for-the-badge&logo=spring)](https://spring.io/projects/spring-boot)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-15%2B-blue?style=for-the-badge&logo=postgresql)](https://www.postgresql.org/)

An interactive management and customer service system for restaurants developed as a backend application, focusing on the practical implementation of the **Spring Boot** ecosystem, **Spring Data JPA**, and database persistence with **PostgreSQL**.

The project features an automated database initialization and data seeding workflow, an interactive console menu with dynamic business logic validation, and a highly decoupled architecture that respects clean software development practices.

---

## Key Features

- **Automated Database Seeding:** Automatic population of the complete menu during application startup via `CommandLineRunner` if the database is empty.
- **Menu Organized by Categories:** Dynamic filtering and categorization of products (`FOODS`, `DRINKS`, and `DESSERTS`) leveraging the Java Streams API.
- **Interactive Console Menu:** Continuous real-time order processing via console inputs using `Scanner`.
- **Business Logic and Validations:**
  - Order checkout protection that prevents the user from exiting the application if there are pending items in the shopping cart.
  - Automatic shopping cart reset and clearing upon successful payment confirmation.
  - Verification of product integrity and existence in the database by ID before adding it to the cart.

---

## Technologies Used

- **Language:** Java 17
- **Core Framework:** Spring Boot 3
- **Persistence & ORM:** Spring Data JPA / Hibernate
- **Database:** PostgreSQL (Tables and relationships mapped and generated automatically by the ORM)
- **Dependency Management:** Maven

## Architecture and Patterns

The project was refactored based on the **Single Responsibility Principle (SRP)** from SOLID, decoupling the control flow, business logic, and terminal rendering operations into specialized layers:

```text
br.com.gabriel.restaurante
├── config
│   └── MenuItemsList        # Initialization and database seeding configuration
├── entities
│   ├── Categories           # Enum managing menu classifications
│   ├── Order                # JPA mapping entity and order total calculation logic
│   └── Product              # JPA mapping entity for restaurant products
├── repositories
│   └── ProductRepository    # JpaRepository interface managing CRUD operations
└── view
    ├── MenuRenderer         # Presentation layer specialized in rendering console outputs
    └── RestaurantMenu       # Controller layer orchestrating user options and the main system loop

```

## Data Model (JPA Mapping)

The database schema was designed using JPA/Hibernate annotations. The product table handles category persistence as Strings, and the order table uses a many-to-many relationship (`@ManyToMany`), which automatically generates the relational join table:

* **`tb_produto`**: Stores the columns `id`, `name`, `description`, `price`, and `categories`.
* **`tb_order`**: Manages order records and primary keys.
* **`tb_order_product`**: An associative join table automatically generated by the JPA relationship to link multiple products to orders.

## How to Run the Project

1. **Clone the Repository:**
```bash
git clone [https://github.com/GabrielDeSousaFerreira/Restaurant.git](https://github.com/GabrielDeSousaFerreira/Restaurant.git)

```


2. **Configure Database Credentials:**
   Adjust your PostgreSQL connection settings inside the `src/main/resources/application.yaml` file:
```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/your_database
    username: your_username
    password: your_password

```


3. **Compile and Run:**
   Run the `RestauranteApplication` class through your IDE (such as IntelliJ IDEA) or via terminal:
```bash
mvn spring-boot:run

```
